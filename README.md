# 🧠 Algoritmo e Pensamento Computacional

> Repositório criado para registrar minha jornada de aprendizado na disciplina de **Algoritmo e Pensamento Computacional** durante a faculdade.

---

## 📚 Sobre o repositório

Este repositório tem como principal objetivo **criar, organizar e guardar os conhecimentos que estou adquirindo ao longo da disciplina de Algoritmo e Pensamento Computacional**.

Aqui serão armazenados meus **códigos, exercícios, testes, projetos, experimentos, fluxogramas e anotações**, permitindo acompanhar minha evolução durante o processo de aprendizagem.

Mais do que apenas guardar códigos que funcionam, a ideia é registrar também meu processo de desenvolvimento: os primeiros exercícios, as dificuldades encontradas, os testes realizados, os erros cometidos e as soluções que fui construindo ao longo da matéria.

Dessa forma, este repositório funciona como uma espécie de **diário técnico da minha evolução na programação**.

---

## 🎯 Objetivos

Os principais objetivos deste repositório são:

- 🧠 Desenvolver meu raciocínio lógico;
- 💻 Aprender e praticar programação;
- 🔢 Compreender conceitos fundamentais de algoritmos;
- 🧩 Aprender a dividir problemas em partes menores;
- 🔄 Praticar estruturas de repetição;
- 🔀 Trabalhar com estruturas condicionais;
- 📦 Aprender a utilizar variáveis e diferentes tipos de dados;
- 📐 Desenvolver algoritmos para resolver problemas;
- 📊 Aprender a representar soluções por meio de fluxogramas;
- 🛠️ Criar pequenos projetos para colocar os conhecimentos em prática;
- 📝 Registrar minha evolução durante a faculdade;
- 🚀 Construir uma base sólida para disciplinas futuras de programação.
