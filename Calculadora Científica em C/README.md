# 🧮 Calculadora em C

Uma calculadora simples desenvolvida em **linguagem C**, com 20 operações matemáticas e um menu interativo no terminal.

O projeto foi desenvolvido com foco em conceitos básicos de programação, como:

- Variáveis
- Operadores matemáticos
- Estruturas condicionais
- Estrutura de repetição `while`
- Entrada e saída de dados
- Validação de entradas
- Operações matemáticas

---

## 📋 Sobre o projeto

Esta calculadora permite realizar diversas operações matemáticas através de um menu interativo.

O usuário pode escolher uma operação, informar os valores necessários e receber o resultado imediatamente.

O programa continua funcionando após cada operação, permitindo realizar quantos cálculos forem necessários.

Para encerrar, basta escolher a opção `0` ou digitar `SAIR`.
